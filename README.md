# 络传智策 · Web

用户信任网络分析与营销策略决策。静态网站，使用 GitHub Pages 托管。

内置 Bitcoin Alpha 和 Bitcoin OTC，覆盖网络分析、关键用户识别、传播仿真与营销决策四个模块。

## 结果来源

`data/alpha.json`、`data/otc.json` 由原 Python 项目的算法对随附数据计算生成。原始文件与 SHA256、生成时间保存在结果中，页面按所选数据集与参数读取对应结果。

传播仿真参数：种子数量 5 / 10 / 20，基础传播概率 0.01 / 0.05 / 0.1；每个组合、每种策略运行 50 次，随机种子 42。有向、评分感知独立级联模型，负边衰减系数 0.2。中心性近似计算沿用原项目。机器学习模型训练数据为 Bitcoin Alpha，对 OTC 的结果属于跨数据集预测，不表示在 OTC 上验证了模型精度。

传播仿真不是实际营销转化统计。页面的策略建议依据当前结果生成，无需第三方 API。

网络图展示入度最高的 160 位用户的关系子图，指标与排名使用完整数据。原始数据中注释记录的网络规模与文件实际内容可能不同，系统以实际解析后的内容为准。

本页面不提供自定义文件上传或在线模型训练。
